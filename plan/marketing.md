# LiveTranslate Promotion Guide

This folder contains assets and copy to help you promote **LiveTranslate** on GitHub and other platforms.

## 🚀 App Description (GitHub / Short)
**LiveTranslate** is a real-time, lightweight speech translation overlay for Windows. It captures your microphone audio and displays live subtitles in multiple languages (English, Vietnamese, Chinese, Japanese, Korean, French) directly on your screen. Powered by Google Gemini and Azure AI.

## ✨ Key Features
- **Real-time Translation**: Instant STT (Speech-to-Text) and Translation.
- **Dual Engines**: Switch between Google Gemini 2.0 Flash and Azure Speech Services.
- **Transparent Overlay**: Beautiful, non-intrusive subtitle window that stays on top.
- **Global Hotkeys**: Toggle listening with a single keystroke (`Ctrl+Shift+L`).
- **Customizable**: Adjust font size, colors, and opacity via the system tray settings.
