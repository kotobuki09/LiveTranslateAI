How it Works

Up and running in under 2 minutes.

1

Install LiveTranslate

Download and install the lightweight application on your Windows device.

2

Configure Settings

Pick your AI engine, audio source (microphone or system audio), language pair, and quality mode via the tray icon → Settings.

3

Translate Instantly

Hit Start Listening (or press Ctrl+Shift+L) and see live subtitles overlaid on any video, call, or game — under 1 second latency.

Cloud mode (Google Gemini / Azure AI) requires an internet connection. An offline mode with local language models is coming soon and will allow full translation without any internet access.

LiveTranslate supports two engines: Google Gemini 2.5 Flash Native Audio — a real-time WebSocket live API that transcribes and translates simultaneously for the lowest possible latency — and Azure Cognitive Services with Azure Translator for enterprise-grade accuracy.
