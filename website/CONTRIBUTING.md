# Contributing to LiveTranslate

First off, thanks for taking the time to contribute! 🎉

The following is a set of guidelines for contributing to **LiveTranslate**. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## How Can I Contribute?

### Reporting Bugs
*   **Use the Bug Report Template**: Fill out the provided template when opening a new issue.
*   **Check for Duplicates**: Search existing issues to see if the problem has already been reported.

### Suggesting Enhancements
*   **Create a Feature Request**: Explain why this enhancement would be useful to most users.
*   **Provide Use Cases**: Show how this new feature would work in practice.

### Pull Requests
*   **Fork the Repo**: Work on your own branch.
*   **Follow the Style**: Try to maintain the existing code style and architecture.
*   **Test your Changes**: Ensure your changes don't break existing functionality.

## Security
If you find a security vulnerability, please do NOT open an issue. Instead, contact the maintainers directly at [Your Contact Method Here].
