# LiveTranslateAI

This is a project that allows users to translate text in real time.

## Author
🌐 https://kngo.netlify.app/<br>

## Installation
To install the package, use the following command:
```
npm install livetranslateai
```

## Usage
You can use this package in your JavaScript code as follows:
```javascript
const translator = require('livetranslateai');
```
